Django Employee Management System

A full-stack web application for managing employee records using Django and MySQL.

Key Features

  • ✔ User authentication (Login / Signup)
  • ✔ Create, update, and delete employee records
  • ✔ Role-based access control
  • ✔ Secure form handling with CSRF protection
  • ✔ Responsive UI using Bootstrap

Tech Stack

Python Django MySQL HTML CSS Bootstrap

How It Works

The frontend renders user interfaces using Django templates and Bootstrap. User actions trigger Django views, which process business logic and interact with the MySQL database via Django ORM.

Authentication and authorization are handled using Django’s built-in auth system.
