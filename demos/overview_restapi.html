Django REST API with JWT Authentication

A secure RESTful API built using Django REST Framework with JWT-based authentication.

Key Features

  • ✔ RESTful API architecture
  • ✔ JWT authentication (Access & Refresh tokens)
  • ✔ User registration & login endpoints
  • ✔ Protected routes using permissions
  • ✔ API testing with Postman

Tech Stack

Python Django Django REST Framework JWT PostgreSQL / SQLite

Sample API Endpoints

POST /api/auth/register/
POST /api/auth/login/
POST /api/token/refresh/
GET /api/users/ (Protected)

How It Works

The API is built using Django REST Framework and follows REST principles. Users authenticate using JWT tokens generated during login.

Access tokens are required for protected endpoints, while refresh tokens allow seamless token renewal without re-authentication.
