FastAPI Booking Management API

A RESTful booking system built using FastAPI with clean architecture principles.

Project Overview

This project is a backend API designed to manage booking operations such as creation, retrieval, updates, and cancellation. The API follows REST principles and separates routing, business logic, and domain models for maintainability and scalability.

Key Features

  • ✔ Create, retrieve, update, and cancel bookings
  • ✔ Pydantic-based request & response validation
  • ✔ Clean architecture with use case separation
  • ✔ Proper HTTP error handling (404 responses)
  • ✔ Versioned API endpoints

Tech Stack

Python FastAPI Pydantic REST API Clean Architecture

API Endpoints

POST /api/v1/bookings/
GET /api/v1/bookings/{booking_id}
PUT /api/v1/bookings/{booking_id}
PUT /api/v1/bookings/{booking_id}/cancel

Architecture

The API is structured using a layered architecture where the FastAPI router handles HTTP requests, delegates business logic to use cases, and returns validated domain models.
