Retail Shelf Analyzer

AI-powered retail shelf image analysis using Segment Anything Model (SAM).

Project Overview

Retail Shelf Analyzer is a computer vision–based system designed to analyze images of retail shelves such as supermarkets and convenience stores. The system uses a foundation AI model to automatically segment product items, estimate stock count, detect empty shelf space, and generate meaningful analytics through a visual dashboard.

This project demonstrates how modern AI models can be applied to real-world retail problems without requiring complex custom model training.

Key Features

  • ✔ Upload retail shelf images
  • ✔ Automatic product segmentation using SAM
  • ✔ Stock count estimation
  • ✔ Empty shelf space detection
  • ✔ Interactive dashboard & report export

Tech Stack

Python FastAPI PyTorch Segment Anything (SAM) OpenCV React PostgreSQL
